# Tic-Tac-Toe

Repository:
https://github.com/erlisaelbasani/tic-tac-toe

## Software Lifecycle

1. User Story is created.
2. User Story is moved to In Progress.
3. A feature branch is created.
4. Feature implementation starts.
5. Unit tests are written.
6. A Pull Request is created.
7. CI/CD runs automatically.
8. Pull Request is merged.
9. User Story is moved to Done.

## Example User Story

US-1: Make a move by choosing an empty square

Process:

- Create feature branch
- Implement feature
- Write tests
- Push changes
- Create Pull Request
- Merge into main
